01 · Perfil

Sistemas backend que siguen siendo rápidos mientras el negocio crece.

Ingeniero Backend Senior con más de 12 años de experiencia diseñando, construyendo y manteniendo aplicaciones escalables para plataformas SaaS y sistemas orientados a datos. Mi stack principal: Node.js, TypeScript y PHP sobre AWS (Lambda, ECS, DynamoDB, S3), con PostgreSQL, MySQL, MongoDB, Docker y Kubernetes. Hoy trabajo en Lean-tech para Slalom, construyendo APIs de alta disponibilidad y servicios backend cloud-native para plataformas empresariales de flujos de trabajo. Antes estuve seis años en QRVEY, plataforma SaaS de analítica embebida, donde llegué a liderar un equipo de 4 personas construyendo pipelines de ingesta de datos y servicios distribuidos para escalar la plataforma con el negocio. La IA es parte de mi día a día: uso agentes como Claude Code, Cursor, GitHub Copilot y OpenCode, modelos locales en LM Studio, e incorporo skills y prompts propios a mis proyectos. Mi enfoque es llevar LLMs y flujos agénticos a sistemas backend en producción, con el mismo énfasis en rendimiento, confiabilidad y arquitectura limpia (DDD, SOLID).
